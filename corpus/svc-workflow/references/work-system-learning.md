# Learn from Avoidable Work

Use this Workflow guidance when rework or a costly correction suggests a useful change in working practice. Return an improvement proposal or a reason to keep the approach.

## Find the Avoidable Cause

Reconstruct relevant requests, commands, diffs, observations, and corrections. Find a decision or feedback point that could have prevented material loss using information and capabilities available then. Use activity counts to locate episodes worth examining. Account for necessary exploration, external outages, and one-time learning when judging avoidable loss.

Challenge the explanation with another plausible cause or contrasting episode. Missing information, inaccessible information, a poor decision, and late feedback require different repairs.

Investigate the difference that could change the improvement. Once the available basis supports a useful intervention, propose it with its reasons and relevant uncertainty; judge further diagnosis by what it could change about that proposal.

## Change the Future Path

State what action, information, constraint, or feedback would change in a matching situation. Prefer removing a needless decision or making the correct action easy over adding warnings.

If a generator drops configuration fields that must survive, repair preservation or detect the loss before writing. If generation preserves them but an outdated example causes bad input, repair the example. Intervene where the cause can be changed; the loss may become visible later.

Stable mechanical relations may justify a script, type, schema, or check; judgment may need a better example or concise guidance. Weigh the loss avoided in future matching work against reading, maintenance, false rejection, and integration cost. Leave the approach unchanged when intervention costs more.

## Check Later Use

For a proposed change, state what improvement a matching situation should reveal. Once adopted, judge result quality, earlier useful action, and avoided rework across later matching uses. Check whether it improves the action or only detects the same rework afterward. Retain, revise, or retire it on that basis.
