# 实现路线

用户已追加 Claude Code 并授权三种来源一起实现。先前“仅调查”的限制已由该请求替代；可修改源码、安装桥接并进行独立有限验收，沿用本机提交／签名安装授权，不发布。App 保持 0.2.0，不增加自动化测试。

1. 实现独立外部执行投影与三种原生控制适配。Pi 通过同 activation Host API；Codex 只连接已存在的共享 app-server；Claude 使用当前原生 agents/logs/stop，并明确 session 范围和交互只读。不伪造机械 ExecutionRecord。
2. 将来源状态、外部执行、日志和精确停止接到公开 CLI 与 App 原有项目／执行页。集成配置保存在 SVC 用户目录；Pi 扩展单独安装、无新模型工具，不改被管理项目。外部停止语义由原控制者负责，SVC 不提供伪造的强杀。
3. 通过独立验收脚本观察原生协议、断线／重载失效、停止精确性、项目归属及数据缺失；不触碰其他用户任务，不发模型请求。既有检查与编译后修复实际发现的问题。
4. 更新权威产品／接口／运行文档，构建同源 CLI runtime，个人开发签名安装 App 0.2.0，核对原偏好和接入状态。Codex 桌面默认共享 socket 当前不存在，作为真实连接限制报告，不能用另起实例冒充接入桌面任务。

独立只读 advisor 认可外部投影与后台会话边界，并指出 Claude 内层命令不等同于会话。已确认用户机器实际存在 kind=background 和 kind=interactive 原生记录；实现会清晰保留这种区别，不宣称内层 Bash 控制完成。
