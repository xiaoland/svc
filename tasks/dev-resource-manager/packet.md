## 产品基线与本轮取舍

SVC Dev 是面向人和 Agent 的开发资源管理产品。App 与 CLI 是图形与程序化入口，产品边界不由 CLI 命令组织决定。资源支持可组合的观察访问、运行、供应销毁、连接和安装更新能力，动作语义归实际项目或系统控制者所有。产品不推断任务，不自动编排依赖或清理无人使用的资源，也不管理各项目自己的业务作业。

用户认可从找到资源、理解状态和作用范围、选择操作到查看结果的使用过程；App 保留菜单栏入口和资源详情，CLI 独立运行。五类控制特性属于表达范围，不承诺内建所有设备或运行时适配。上述接受的事实已同步至 [产品文档](../../docs/prd/development.md)。

项目外登记的需求证据不足：Velune 禁止引入 SVC 是约束，不是必须将其纳管的需求；没有观察频次或节省时间数据。项目声明已能描述远端探测、主机共享资源和外部控制脚本。因此本轮推荐采用项目内声明与本机 overlay 这一个来源，撤回独立登记承诺，不以新增全局目录、桥接配置工程或任意配置路径变相实现它。若之后出现明确且反复的个人跨项目目录需求，再重新评估。
