# 界面信息收敛

## 目标与约束

用户要求默认界面更简单，重要信息自然可见，需要时能逐层展开。延续迭代协作，以及本机自由提交、开发签名安装授权。只改变 App 呈现，不改变 CLI、归属、采样、控制权限和配置合同。禁止新增自动化测试，使用有限离屏脚本和既有检查；不用 computer use、常驻观察宿主或压力负载。保留两个独立验收项目与真实用户偏好。

## 实施判断

当前界面把主机全部指标、项目路径、无用量占位、观察原始值、每个动作的效果说明与执行身份并列展示，导致主状态和动作不突出。默认保留具名状态、常用操作、项目 CPU／内存摘要及错误；本机详细指标、项目磁盘和进程数、原始观察证据及执行身份按对象展开。普通终止直接可见，强制终止位于详情且保留确认。修改／删除／未知的数据影响不能因收敛而隐藏到动作之后。具名观察不被改写成通用“运行／停止”，无采样不能显示成零。

继续用系统 SwiftUI 和 NSButton，不改窗口／侧栏管理，不引入新的主题或背景透明。展开状态为局部视图状态，不写入项目和 Section 偏好。权威行为文档为 docs/product-tdd/macos-client.md，版本和发布说明只推进 App。

## 验证与交付

以已记录的真实 CLI 数据重放，检查 420 宽面板、740／1040 主窗口，以及正常、未知、破坏性动作、活动执行等状态。离屏脚本操作真实 NSButton 的展开入口，确认隐藏信息可达、默认常用动作仍可用、强制操作没有失去确认。复用既有测试，不增加用例；最终编译和个人开发签名安装后核对版本、签名、原偏好与配套 CLI 保持一致。人类体验验收不由脚本代替。

已完成视图收敛、权威文档和 App 0.6.1 说明，CLI 继续使用 18.2.0。原生构建通过，既有 Swift 检查正常结束；其中真实 CLI 生命周期和框架离屏渲染三个条件检查未启用，本轮使用独立脚本覆盖相关呈现，不把跳过项当作已运行。没有改动任何测试或 CLI 源。

[离屏观察](evidence/interface.json)使用已保存的实际 CLI 数据重放，覆盖 420 面板、740／1040 主窗口、明暗模式、资源展开、执行展开及强制终止确认。资源区域收起高度 131 点，展开 443 点；普通终止在默认区域可见，强制终止只有详情中可达且点击后仍要求确认。未知观察和删除数据的影响通过专门的呈现输入检查。脚本只触发自己宿主内的产品 NSButton，没有发出真实终止／删除请求；窗口没有显示，App 没有激活，不是物理键盘或 VoiceOver 验收。确认区首轮发现长句截断，已修正并重新观察，argv 与来源证据也可完整换行。
