# 界面信息收敛

## 目标与约束

用户要求默认界面更简单，重要信息自然可见，需要时能逐层展开。延续迭代协作，以及本机自由提交、开发签名安装授权。只改变 App 呈现，不改变 CLI、归属、采样、控制权限和配置合同。禁止新增自动化测试，使用有限离屏脚本和既有检查；不用 computer use、常驻观察宿主或压力负载。保留两个独立验收项目与真实用户偏好。

## 实施判断

当前界面把主机全部指标、项目路径、无用量占位、观察原始值、每个动作的效果说明与执行身份并列展示，导致主状态和动作不突出。默认保留具名状态、常用操作、项目 CPU／内存摘要及错误；本机详细指标、项目磁盘和进程数、原始观察证据及执行身份按对象展开。普通终止直接可见，强制终止位于详情且保留确认。修改／删除／未知的数据影响不能因收敛而隐藏到动作之后。具名观察不被改写成通用“运行／停止”，无采样不能显示成零。

继续用系统 SwiftUI 和 NSButton，不改窗口／侧栏管理，不引入新的主题或背景透明。展开状态为局部视图状态，不写入项目和 Section 偏好。权威行为文档为 docs/product-tdd/macos-client.md，版本和发布说明只推进 App。
