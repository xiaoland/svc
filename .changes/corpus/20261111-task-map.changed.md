summary: "Replace Track/Phase/Cell/Slice topology with Task Map (Track/Convergence/Plan)"
---

Simplify planning topology from 8 units (Track, Phase, Cell, Plan, Slice, Step, Assignment, TBC) to 3 units (Track, Convergence Point, Plan). Add observable trigger: use Task Map when two or more work lines can advance in parallel and their completion times differ by more than one day.

**Changes**:
- Retire Phase, Cell, Slice, Step, Assignment as management units
- Replace with Task Map: Track (independent work line), Convergence Point (sync point), Plan (linear steps)
- Delete `assets/task-map.template.md` and `assets/cell.template.md`
- Rewrite `references/planning.md` with Task Map definition and migration guidance
- Simplify `plan.template.md` to linear ordered steps
- Update `SKILL.md` Plan and Coordinate section with trigger conditions
- Simplify `references/growth.md` to new 3-unit topology

**Rationale**: Survey of 233 consumer Task Packets showed 0 usage of Phase/Cell/Slice per definition. Task Map retains Track (proven useful) while removing unused formalism.

**Migration**: Existing Packets using Track continue unchanged. Phase/Cell references (if any) should be flattened to Track plans with convergence points marked.
