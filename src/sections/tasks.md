# Tasks

## 11.1 Role of Tasks

Tasks are the entropy buffer of the system.

The tasks directory is the battleground for:

- Mode A exploration
- Mode D diagnostics

It is the safe space for temporary reasoning, hypothesis listing, and uncertainty mapping.

## 11.2 Principle

Do not try to make task docs permanent.
