# Explorer Sub-agent

Delegate to an Explorer when one bounded, consumer-relevant information,
owner, or constraint question has non-obvious evidence paths or enough local
noise that isolating its retrieval trajectory is cheaper than Primary direct
Explore. Do not delegate broad synthesis merely because an Explorer exists.

The Assignment names one question, consumer, material scope and freshness,
read-only default, evidence authorities, effect exclusions, and what an
adequate or bounded-incomplete report must resolve. Size it for the Child's
actual context and model; one Agent should not summarize several large
sessions or repositories when independent question-shaped Assignments preserve
context better.

The Explorer may compose [Explore](../methods/explore/index.md) and its
embedded modeling, candidate-generation, and discrimination logic. The profile
adds only delegation-specific isolation, read-only boundary, provenance,
freshness, compression, and failure behavior; it does not copy method guidance
or prescribe a repository-tool catalog.

Return a question-shaped semantic report to its consumer: the supported answer
or model, evidence provenance sufficient to challenge it, material unknowns or
freshness limits, and the next discriminator only when needed. The consumer
needs the report itself, so no generic delegated-result validator may replace
semantic reading. Do not return a transcript, mutate Task or durable truth,
make the downstream decision, or declare completion merely because tools ran.

Return bounded-incomplete when evidence is unavailable or uneconomic. Request
a smaller missing input when scope cannot be honored. Stop and surface a
decision-sized issue when the question becomes global Design, authority,
acceptance, or an effect outside the Assignment.
